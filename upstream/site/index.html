Driver facts

  • MaliSX2 0.5.0: `/dev/mali0`, Android API 29+, experimental, no MSAA.
  • PanVK r10: `/dev/mali0`, Android API 31+, experimental/non-conformant.
  • System Vulkan: always available recovery path.
  • Turnip T30: Qualcomm KGSL/Adreno only; never use it on Mali.

A launcher option is not proof of compatibility. Confirm [vulkan-device] profile= and the final driver identity in logcat/game.log.
